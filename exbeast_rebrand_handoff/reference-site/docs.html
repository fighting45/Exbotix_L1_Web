Overview

ExBeast is an EVM-compatible Layer 1 blockchain that converges AI, exchange infrastructure, DeFi and SocialFi into a single programmable ecosystem. Because ExBeast is EVM-equivalent, any contract, tool, or wallet that works with Ethereum works here with no code changes.

  • Consensus: Proof of Work
  • Gas token: EXBT
  • Block time: ~12.8 seconds · ~100 TPS
  • Compatibility: Solidity, Hardhat, Foundry, ethers.js, web3.js, MetaMask, Remix

Quickstart

Configure your project to target ExBeast in seconds.

terminalcopy
$ npm install --save-dev hardhat
$ npx hardhat init

Deploy a contract

Add ExBeast to your hardhat.config.js and deploy exactly as you would on any EVM chain.

hardhat.config.jscopy
module.exports = {
  solidity: "0.8.24",
  networks: {
    // Mainnet — Chain ID 11311
    exbotix: {
      url: "https://rpc.exbotix.net/",
      chainId: 11311,
      accounts: [process.env.PRIVATE_KEY],
    },
    // Testnet — Chain ID 11211
    exbotixTestnet: {
      url: "http://testnet.rpc.exbotix.net",
      chainId: 11211,
      accounts: [process.env.PRIVATE_KEY],
    },
  },
};
deploy
$ npx hardhat run scripts/deploy.js --network exbotix
// ✓ Contract deployed to 0x9f… on ExBeast Mainnet

$ npx hardhat run scripts/deploy.js --network exbotixTestnet
// ✓ Contract deployed to 0x9f… on ExBeast Testnet

RPC methods

ExBeast supports the standard Ethereum JSON-RPC API on both networks — point at rpc.exbotix.net for Mainnet or testnet.rpc.exbotix.net for Testnet. A few common calls:

curl
# Mainnet
$ curl https://rpc.exbotix.net/ \
  -X POST -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_chainId","params":[],"id":1}'
// → { "result": "0x2c2f" }  (11311)

# Testnet → http://testnet.rpc.exbotix.net
// → { "result": "0x2bcb" }  (11211)
  • eth_blockNumber — latest block height
  • eth_getBalance — EXBT balance of an address
  • eth_sendRawTransaction — broadcast a signed tx
  • eth_call — read contract state
